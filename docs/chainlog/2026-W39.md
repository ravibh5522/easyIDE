  - The 120 ms debounce now applies only to real edits, not to opening a file, switching tabs, scrolling or theme changes.
  - Tokenizer state is kept for the 8 most recent tabs (it was the active tab only, so every switch re-tokenized from line 0).

- Did not add a SQLite or disk token cache. TextMate `StateStack` cannot be serialised, Room is already ruled out ([0005](../decision/0005-sandbox-environment-sharing-model.md)), and the cold cost is regex compilation, which prewarm addresses.
