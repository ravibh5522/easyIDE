## 2026-09-29 10:00

- Added [terminal-audit.md](../sandbox-runtime/terminal-audit.md): static audit of terminal/agent/multi-session problems against the one-sandbox-one-OS goal (shared `/workspace` path, silent shell eviction, phantom-process killer, per-command proot cold starts, root/dev split). No code changed.
- Fixed the findings that need no new architecture, from that audit: per-project guest alias `/projects/<id>` for terminals (F1); idle-first eviction plus a toast when running shells are ended (F2); SIGKILL-by-Android message (F3); guest defaults once per rootfs under a lock with atomic account-file writes (F4); named terminals as the default user and `USER`/`LOGNAME`/`SHELL` on the root shell (F5); Cleanup keeps `/tmp` while a workspace is live (F7). Not built: per-environment supervisor (F4) and AI-tools layer (F6), both need an ADR and a device spike.
- Fixed npm cache corruption under proot (language-server install errors): Node preload that copies instead of hard-linking into `_cacache`, plus a one-time purge of caches already broken (`NodeCacheGuard`). Verified on a device with a fresh Ubuntu + Node.js environment. See F9 in the audit.
- Terminals now mount every project of the environment at `/projects/<project name>` and start in their own, so agents can find sibling projects. Verified on a device (`ls /projects/easyIDE` from another project). See [0033](../decision/0033-projects-mounted-by-name-in-every-terminal.md). Bumped to `0.2.0-beta.7`.
- Fixed Claude Code failing to install (`native binary not installed`): the root cause was Ubuntu's Node 18 / npm 9.2, so every environment now gets `easyide-install-node` (current Node LTS from nodejs.org, checksum-verified), used by the Node preset and the extension install recipes. See F10 in the audit.
