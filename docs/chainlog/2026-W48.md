# Chainlog — 2026-W48

## 2026-11-23 12:00

- Auto save: `files.autoSave` / `files.autoSaveDelay` settings (`EditorSettingsSchema`), a switch in the editor title row (`WorkspaceScreen`), and a debounced save in `FileDocument`.
- Run actions now install what is missing: `WorkspaceExtensionHost.runInTerminal` checks the tool a command needs against `Toolchains` (new table: python3, node, gcc/g++, go, rust, java, ruby, php, lua, perl) and, when absent, installs it and runs the file in one root shell, non-interactively. The C/C++ pack gained `cpp.runFile` / `cpp.runCFile` (g++ / gcc) in the editor title bar.
- Fixed a crash on first launch: `SandboxForegroundService.stop()` called `stopService()` before `onStartCommand` had run, which Android turns into `ForegroundServiceDidNotStartInTimeException`; stop now goes through the service itself.
- Why: first run of any language failed with "command not found"; a fresh install crashed on open. Verified on device (canary): Python and C++ run from the play button, auto save saves, app opens. Not fixed: clangd still crashes as a language server (works when run directly in a terminal).
