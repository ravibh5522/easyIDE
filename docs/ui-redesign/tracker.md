## R1 swap (done)

The temporary adapters (`LegacyAdapters.kt`, `PanelBinding.spansWindow`, `HomeScreen`, `SettingsScreen`, `ExtensionsScreen`) are gone. What the shell does now:

1. `AppRenderers` binds `home.projects`, `settings.categories` and `extensions.list` to their panels and `easyide.project`, `easyide.settings`, `easyide.extension` to their pages. A panel binding may carry a `stageDefault` shown on a wide window while no document is open: Home's is `HomeNowPage`, Settings' is the Appearance page.
2. `DocumentRenderer.Title` (composable) gives a tab or compact title bar the subject's own name (project name, extension name, settings category); the type's one-word title stays as the fallback, so a missing subject still has a title.
3. Dialogs that belong to no panel (`HomeDialogHost`, `ExtensionsDialogs`) are mounted once through `ShellHost(dialogs = ...)`.
4. Each panel draws its own title row (Home, Extensions, Settings); `PanelHost` adds none, so there is exactly one header.
5. Baseline profile: the generator taps the project row by `kit:project-row`, then the page's `kit:project-open` button; `ShellHost` exposes test tags as resource ids. Regeneration needs a device (`:app:generateBaselineProfile`) and has not been run.
6. Not done on purpose: extension contributions to the layout catalog (R4 feeds the registries; `LayoutCatalog.of` already names the pack), and duplicate/clone/import still select the new project in `HomeViewModel` without opening its page.
