# easyide.python

The pack is Apache-2.0, like the other first-party packs (decision 0015).

- `syntaxes/python.tmLanguage.json`: the TextMate Python grammar (MagicPython lineage) from the
  `tm-grammars` npm package, **MIT**. It moved here from the app's bundled grammars on 2026-09-24.
  See NOTICE.md at the repository root for the grammar set's provenance.
- `language-configuration.json`: VS Code 1.139.0 built-in Python language configuration, **MIT**.
