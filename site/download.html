Install

  1. Download the APK above on your tablet or phone.
  2. Allow installs from your browser when Android asks (Settings > Apps > Special access > Install unknown apps).
  3. Open easyIDE and follow setup: it asks to keep running in the background and to show notifications, then downloads and installs Ubuntu (Wi-Fi recommended).

Requirements

  • Android 8.0 or newer
  • An arm64-v8a or x86_64 device
  • Free storage for Ubuntu and the toolchain you pick
  • No root

Upgrading

Every release is signed with the same key, so a new APK installs over the old one and keeps your projects and environments.

Verify the download

Each release lists the APK's SHA-256. Compare it with the file you downloaded:

sha256sum easyIDE-v*.apk

Privacy

On first launch easyIDE asks you to agree to technical diagnostics (device model, Android version, app version, feature use, crash logs) and release announcements. It never collects your files, code, commands, terminal output or personal details. Turn it off any time in Settings > Privacy. Details in the README.
