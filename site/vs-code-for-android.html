VS Code for Android: your options in 2026, and a native alternative

By Ravi Kumar, lead developer · October 14, 2026

Short answer: Microsoft does not make a VS Code app for Android. VS Code's official downloads are Windows, macOS and Linux. On an Android tablet you can use VS Code in the browser, run code-server yourself, connect to a remote machine, or use a native IDE built the VS Code way. Here is what each gives you, as of October 14, 2026.

1. vscode.dev and github.dev in the browser

VS Code for the Web runs entirely in the browser and Microsoft documents it as usable on tablets. The trade-off is that nothing runs locally: Microsoft's documentation states that the terminal and debugger are not available, and only web extensions install (themes, snippets and grammars work; extensions that run code must support the browser sandbox). Git works through the GitHub and Azure Repos integration rather than a local git.

Good for quick edits to a GitHub repository. Not for running Python, Node.js or tests.

2. code-server inside Termux

code-server (MIT) is the real VS Code UI served from your device and opened in the browser. Its documentation describes installing it in Termux from the Termux User Repository. You get VS Code's terminal and git UI, with some documented limits:

  • Extensions come from Open VSX, not Microsoft's Marketplace.
  • On Termux, Android is treated as an unsupported platform, so only web extensions download automatically; the docs list manual .vsix installs as a workaround.
  • Git does not work in /sdcard, and keyboard handling needs a setting change.

Good for people who want exactly VS Code and are comfortable maintaining a Termux setup.

3. Codespaces or a remote tunnel

GitHub Codespaces and VS Code Remote Tunnels give you full VS Code with a terminal, but the code runs on another machine. You need a connection the whole time, and Codespaces is billed by usage beyond its free quota.

4. easyIDE: a native, VS Code-style IDE

easyIDE is an Android app, not a browser tab, built around the same ideas as VS Code, with a Linux userland on the device:

  • VS Code-shaped workspace: activity rail, side bar, split editor groups, breadcrumbs and a bottom panel, adapting to phones.
  • VS Code's TextMate grammars for 229 languages, bundled for offline use.
  • Language servers (completion, diagnostics, rename, go-to-definition) installed per language pack: Python, TypeScript, Rust, Go, C/C++ and more.
  • A real Ubuntu 24.04 terminal, no root, with apt.
  • Git with a VS Code-style history graph, staging and amend.
  • VS Code icon themes from Open VSX install as is.

Honest limit: VS Code extensions that run code (GitLens, debugger extensions and so on) do not run in easyIDE. Only declarative packs and icon themes install.
