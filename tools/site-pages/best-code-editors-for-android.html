Coding on Android has never had more options. This list covers the editors and IDEs that are maintained today, what each is best at, and the trade-offs, as of October 14, 2026. We make easyIDE, so it is listed first; every other entry is described from its own documentation and store listings.

1. easyIDE: a VS Code-style IDE with Ubuntu

A native app with a VS Code-shaped workspace, language servers for many languages, built-in git with a history graph, and a real Ubuntu 24.04 terminal without root. Presets install Python, Node.js LTS or build tools. Best for general development on a tablet. Gaps: beta, no debugger, VS Code extensions that run code do not work. Download.

2. Acode: the popular all-rounder

MIT-licensed and very actively developed, with a large plugin store, a built-in Alpine Linux terminal, language-server support, SFTP/FTP and live previews. The free version shows ads; Pro removes them. Best for web development and remote file editing. See easyIDE vs Acode.

3. Termux with Neovim or Vim

A terminal with the largest package collection on Android, plus proot-distro for full distributions. Install Neovim and configure its built-in language-server client yourself. Termux recommends its F-Droid or GitHub build over the experimental Play build. Best for terminal-first developers.

4. code-server: real VS Code in the browser

Coder's open-source VS Code server, installed inside Termux and opened in the browser. You get the genuine VS Code UI, with Open VSX extensions and some documented Android limits. Best for people who need VS Code exactly. See VS Code for Android.

5. Code on the Go: Android apps on Android

The official successor to AndroidIDE (now archived), updated weekly, for building Kotlin and Java Android apps on the device, with a UI designer. Best for Android app development without a computer.

6. Spck Editor: web development and git

A polished editor for HTML, CSS, JavaScript and TypeScript with a strong git client and previews. The Node terminal is a premium feature. Best for front-end work.

7. Squircle CE: a fast, lightweight native editor

Apache-licensed, no ads, with git, SFTP/FTP and support for 30+ languages. No terminal or language servers in its released version. Best for quick edits.

8. vscode.dev: zero install

Microsoft's VS Code for the Web works in a tablet browser with no terminal or debugger and web extensions only. Best for quick changes to GitHub repositories.

No longer available

Dcoder shut down on March 31, 2026. AndroidIDE is archived and its developers point to Code on the Go.

How to choose

  • Real toolchains (Python, Node.js, compilers) in an IDE: easyIDE.
  • Web development, plugins, SFTP: Acode or Spck.
  • Terminal and Vim: Termux.
  • Exactly VS Code: code-server or vscode.dev.
  • Android apps: Code on the Go.
