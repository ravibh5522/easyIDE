Claude Code is a command-line tool, and it needs a real Node.js and a real shell. easyIDE gives an Android tablet both, so the CLI runs on the device next to your editor and git.

Claude Code is Anthropic's software and needs your own Anthropic account. easyIDE does not include or redistribute it; you install it yourself, as below.

1. Get an environment with Node.js

Install easyIDE (download) and, on the Linux step of setup, choose Ubuntu + Node.js. That preset installs the current Node.js LTS from nodejs.org (checked against its published checksums), not Ubuntu's older packaged Node.

Using a different preset? In any easyIDE terminal run easyide-install-node, which installs the same Node LTS.

2. Install the CLI

Open a project, open a terminal and run:

node --version
npm install -g @anthropic-ai/claude-code
claude --version

If an older environment still has Ubuntu's Node 18, the install can fail with "native binary not installed". Run easyide-install-node to move to the current LTS, then install again. easyIDE 0.2.0-beta.8 and later do this for new environments.

3. Sign in and start

cd /projects/my-app
claude

The CLI prints a sign-in link; open it in the tablet's browser and come back. From then on Claude Code reads and edits the files in your project, and every change shows up in easyIDE's editor and in Source Control, where you can review the diff before you commit.

Why it works here

  • A real Linux userland: Ubuntu 24.04 under PRoot, so npm global installs, native binaries and child processes behave as on a laptop.
  • Every project is mounted at /projects/<name> in every terminal of its environment, so the agent can read a sibling project when you ask it to.
  • It keeps running in the background while a foreground service holds the sandbox open (setup asks for the battery exemption for this).

Good to know

  • The VS Code extension for Claude Code does not run in easyIDE: extensions that execute code are not supported yet. The CLI is the way in.
  • Long sessions use battery and data; plug in for big refactors.
